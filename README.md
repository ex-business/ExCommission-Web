# ExCommission-Web

代理业务前端，提供运营管理后台和会员代理页面。规则计算、审批及账务由独立后端 [ExCommission](https://github.com/ex-business/ExCommission) 处理。

## 管理后台

配置代理规则和等级条件，完成试算、发布、结算审核及报表查询。

![方案条件配置页面](docs/images/conditions.jpg)

## 会员页面

查看邀请奖励、团队进度和佣金收益，分享邀请链接并领取已达标奖励。运营账号与会员账号分别登录。
