# 代理方案发布与运行

入口：方案配置 > 方案发布与运行。旧方案管理、原代理配置及历史功能保留。

| 状态 | 新计算和结算 | 历史与旧权益 |
| --- | --- | --- |
| 未启动 | 不产生 | 可以查看 |
| 运行中 | 到达生效时间后按条件计算，关账后日结 | 可以查看并继续处理 |
| 已停止 | 不产生 | 保留记录，已产生权益仍可审核、领取、冲正 |

新建或复制方案，设置适用来源、事实会员、币种、时区、条件、奖励、层级算法和去重规则。多方案可叠加，或在同组按优先级、互斥处理。预检和试算通过后提交独立审批，申请人不能批准自己的申请。

恢复启动不自动补结算之前停止区间。运行中连续修订允许同一运行区间的旧版本按原配置结清。原有代理配置作为兼容方案独立叠加，如不希望继续计奖，应在原配置页通过审批停用新增计奖。

页面模块：

- `Programs.tsx`：加载、申请和试算编排。
- `ProgramEditor.tsx`：条件、运行状态、生效时间和计算器。
- `ProgramHistory.tsx`：版本、权益、日结和事件命中记录。
- `programModel.ts`、`programRequest.ts`：类型、展示和请求字段白名单。
- `ProgramRewards.tsx`：会员本人独立方案奖励与领取。

每笔奖励使用原方案币种精度，不混加 USD/BTC。查看原有奖励记录、审核金额和会员明细时也按冻结精度显示。新会员提示与原有界面继续保留，多方案奖励独立列出。
