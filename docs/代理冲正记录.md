# 代理冲正记录

入口：结算与审核 → 退款与调整 → 代理冲正记录。

页面只读查询本站GET /v1/affiliate/reversals，显示退款/撤单号、原业务单、奖励与会员、原目标额、调整后目标额及新增追偿；可按已调整、待追偿、待复核补偿筛选。展开“已接收退款和撤单”可查看没有产生新差额的接收事件。

![代理冲正记录](images/affiliate-reversals.png)

使用公共运营账号登录，沿用原站点会话和实时授权；页面不接触来源签名密钥。浏览器POST /v1/affiliate/reversals始终拒绝，由受信来源系统直连。原通用退款及追偿入口保留。

金额明确展示最小货币单位；当前最多查询1000条，不提供自动扣钱包、自动抵扣或追偿结案操作。正向补偿仅标记待复核，不自动增加派发。
